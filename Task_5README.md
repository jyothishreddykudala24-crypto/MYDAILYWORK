# Task 5 – Handwritten Text Generation

## Internship: Machine Learning – MyDailyWork

### Project Description
This project implements a Character-Level LSTM (Recurrent Neural Network) to generate handwritten-style text using the IAM Handwritten Dataset.

### Dataset Used
IAM Handwritten Dataset (words.txt)

### Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab

### Model Used
- Character-Level LSTM
- Softmax Output Layer
- Adam Optimizer

### Outcome
The model successfully generates handwritten-style text by learning sequential character patterns.
